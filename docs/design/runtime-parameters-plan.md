**状态：** 第 3 节决策全部按建议确认（2026-11-26）；原型（Design 画布“运行参数配置原型”，三块画板：运维设置、参数总览、各业务页面改动）待确认。
**更新日期：** 2026-11-26（RP1～RP9 按建议确认）；2026-11-26（初稿）
**依据：** 2026-11-26 对超时、并发、资源与保留期参数的代码盘点（第 4 节）；[错误记录与使用情况方案](error-tracking-usage-plan.md) OB10（保留期）；[钉钉接入方案](dingtalk-integration-plan.md) DT30（钉钉参数已在页面配置）；[功能规则](../development/feature-rules.md)第 13 节（管理端模块权限）。
**关联：** [架构总览第 10 节](../development/overview.md#10-当前边界与独立开发)、[内部端口与契约](../development/internal-ports.md)、[数据模型](data-model.md)、验收目录 `e2e/catalog/admin-platform.md`。

## 1. 背景与目标

系统里的超时、并发、资源上限与保留期，大部分写死在代码里，少数在环境变量里，只有 Agent 运行限制、Runtime 容量与超时、钉钉参数可以在管理端修改。管理员遇到“运行总是超时”“磁盘余量不足拒绝执行”“知识库检索失败”时，既不知道当前生效的值，也不知道去哪里改。

目标：

1. **能改的分散在各业务页面修改**，沿用该模块的权限与审计；
2. **运维自己的参数集中在“运行参数”页面修改**；
3. **所有参数集中在一个只读总览查看**：当前值、来源（页面配置 / 环境变量 / 系统内置）、生效时机、去哪里改，以及每条运行链路实际生效的超时。

## 2. 边界

- **不开放安全隔离参数。** 执行容器与 Python 沙箱的内存、CPU、进程数、文件大小（`ulimit`）只读展示，不可修改（功能规则：执行前复核等安全约束不能豁免）。
- **不开放与 DSH 耦合的参数。** 模型重试策略（`MODEL_ROUTE_RETRY_POLICY`）、DSH 工具调用超时（patch 中 `toolCallTimeoutMs`）、平台工具契约超时不开放；调整须改代码并随 DSH 适配一起评审（AGENTS.md“Agent 执行统一使用 DSH”）。
- **不开放实现细节。** 轮询间隔、心跳、宽限期、清理批量、缓存大小不进总览。
- **不开放上传与产物大小。** 前端校验、Schema、文本提取共用这些值，单独可配会造成前后端不一致；总览只读展示。
- **启动参数仍留在环境变量。** 数据库连接池、密码哈希并发、会话密钥等只在启动时生效或涉及密钥，不进页面；总览只展示非密钥项，标注“改环境变量后重启”。
- **单进程部署。** 保存后刷新本进程缓存即生效；多实例同步不在本期。

## 3. 决策

| 编号 | 决策 | 可选做法 | 结论 |
| --- | --- | --- | --- |
| RP1 | Runtime 容量与单次执行超时放在哪里改 | (a) 留在 Runtimes 页（现属 `connector` 模块），运行参数页只放 `ops` 模块参数；(b) 迁入运行参数页，改归 `ops` 并同步改 AP 与功能规则第 13 节 | **已确认（2026-11-26）：** (a)。不改权限归属；总览照样显示并链接过去 |
| RP2 | 页面配置如何存储 | (a) 新增通用参数表，代码里登记每个参数的模块、类型、默认值、范围、生效时机；(b) 各模块各自加表或加列 | **已确认（2026-11-26）：** (a)，模型路由首包超时例外（随路由存，见 RP5） |
| RP3 | 登录会话有效期（现 `DSH_WORK_SESSION_TTL_SECONDS`，8 小时）是否改为页面配置 | (a) 是，放“员工与权限”，只影响之后的登录；环境变量只在页面从未保存过时作初始值（同 DT30）；(b) 保持环境变量 | **已确认（2026-11-26）：** (a) |
| RP4 | 知识库检索与上传超时 | (a) 在“企业知识库”页新增“连接与超时”区块：连接地址仍来自环境变量、只读显示，检索与上传超时可改；(b) 第一期不做，只在总览只读显示 | **已确认（2026-11-26）：** (a)。WeKnora 部署位置与文档大小差别大，这两项最常需要调 |
| RP5 | 模型等首个响应的超时（现全局 120 秒） | (a) 按模型路由设置，默认 120 秒；(b) 全局一个值，放运行参数页 | **已确认（2026-11-26）：** (a)。慢模型与快模型同用一个值不合理 |
| RP6 | 错误记录 90 天、页面访问 180 天是否改为可配置（**变更 OB10**） | (a) 可配置，默认仍为 OB10 的值；(b) 维持 OB10 固定值 | **已确认（2026-11-26）：** (a) |
| RP7 | 超时上下级不一致时怎么办 | (a) 不拒绝保存：保存时提示，总览显示每条链路实际生效的值和起限制作用的一项；(b) 保存时拒绝 | **已确认（2026-11-26）：** (a)。现有代码就是静默取最小值（4.3），拒绝会让已有配置无法保存 |
| RP8 | 总览谁能看 | (a) 有 `ops` 查看权限即可看全部参数，“去修改”链接按目标模块权限显示；(b) 只有平台管理员 | **已确认（2026-11-26）：** (a) |
| RP9 | 后台车道并发是否开放 | (a) 只开放自动任务并发（现写死 2）；(b) 全部只读 | **已确认（2026-11-26）：** (a)。试运行 2、项目档案员 1、会话摘要按代码固定 |

## 4. 现状

### 4.1 已能在页面修改

| 参数 | 默认 | 范围 | 页面 / 模块 |
| --- | --- | --- | --- |
| Agent 运行超时 | 300 秒 | 30～600 秒 | Agent 详情 → 能力 / `agent` |
| Agent 工具调用次数 | 20 | 1～100 | 同上 |
| Agent 最大输出 | 64 KB | 1 KB～1 MB | 同上 |
| Runtime 容量（Worker 并发） | — | 1～1000 | Runtimes / `connector` |
| Runtime 单次执行超时 | 300 秒 | 1～60 分钟 | 同上 |
| 钉钉会话有效期、待绑定凭证有效期、每日代绑上限、接口超时 | 12 小时、5 分钟、50、10 秒 | — | 钉钉集成 / `dingtalk`（DT30；环境变量只在从未保存时作初始值） |

### 4.2 已废弃但仍可能被误以为有效

- `DSH_WORK_EXECUTION_MAX_CONTAINERS`：已删除，启动时只打印警告（`attempt-execution-containers.ts:61`）。执行容器每个 Attempt 一个，并发由 Runtime 容量限制（`postgres-run-repository.ts:493`），后台车道合计最多到容量减 1。
- `DSH_WORK_DIRECTORY_SYNC_INTERVAL_SECONDS`：已忽略（`identity/config.ts:9`）。

总览不展示这两项；部署手册与环境变量示例如仍有提及，一并删除。

### 4.3 超时实际怎么生效

- 员工对话：`min(Agent 超时, Runtime 超时, 调用方上限)`（`attempt-dispatcher.ts:163`），不一致时静默取最小值，没有提示。
- 管理助手：`min(180 秒, Runtime 超时)`；会话摘要与项目档案员：`min(120 秒, Runtime 超时)`。
- 模型网关等响应头 120 秒；DSH 对超时、限流、服务端错误最多重试 2 次，最坏约 3 倍时长，仍受上面的运行超时截断。

### 4.4 发现的口径不一致

管理助手修改 Agent 时预校验允许超时 1～3600 秒、工具调用 1～10000 次、输出 1～10,000,000 字节（`admin-assistant-service.ts:534`），而 Agent 定义边界是 30～600 秒、1～100 次、1 KB～1 MB（`agent-spec.ts:54`）。确认卡片可能展示一个确认执行时才被 Agent 定义校验拒绝的值。本方案实施时改为共用 `AGENT_SPEC_BOUNDS`。

### 4.5 读取时机

多数候选参数是模块级常量（如 `WORKSPACE_LIMITS`、`WEB_FETCH_MAX_PER_ATTEMPT`、`ERROR_RETENTION_DAYS`），或启动时读一次（`DSH_WORK_SESSION_TTL_SECONDS`）。改为可配置必须改成每次使用时读取，这是主要工作量。

## 5. 风险

| 风险 | 处理 |
| --- | --- |
| 调得过小导致大面积失败（例如检索超时 1 秒） | 每个参数登记最小值与最大值，服务端校验；页面显示默认值与“恢复默认” |
| 磁盘余量阈值调低后盘被写满 | 下限 2 GB；低于默认值时保存前二次确认 |
| 页面值与环境变量谁优先说不清 | 统一规则：页面保存过就以页面为准，环境变量只作初始值；总览“来源”列写明 |
| 超时层级不一致让人困惑 | RP7：保存时提示、总览显示实际生效值与起限制作用的一项 |
| 保留期缩短会删掉已有数据 | 缩短保留期时提示“下次清理将删除早于 N 天的记录”并二次确认 |
| 总览泄露密钥 | 服务端按白名单返回，密钥类变量只返回“已配置 / 未配置” |

## 6. 方案

### 6.1 数据

新增迁移 `0136_platform_settings`：

| 列 | 说明 |
| --- | --- |
| `tenant_id`、`key` | 主键 |
| `value` | `jsonb` |
| `revision` | 乐观锁 |
| `updated_by`、`updated_at` | 最后修改人与时间 |

代码中的参数登记表（`domain/platform-settings.ts`）是唯一口径：键、所属模块、类型、单位、默认值、最小值、最大值、生效时机、修改位置。服务端校验、总览接口、前端表单都从这里取，前端不另写常量。

模型路由首包超时随路由保存：迁移 `0137_model_route_headers_timeout`，`model_routes` 加 `headers_timeout_seconds`，网关按路由读取。

### 6.2 参数清单

**可修改**

| 参数 | 默认 | 范围 | 生效时机 | 修改位置 / 模块 | 决策 |
| --- | --- | --- | --- | --- | --- |
| 磁盘最低剩余空间 | 10 GB | 2～500 GB | 下一条命令 | 运行参数 / `ops` | — |
| 磁盘最低剩余比例 | 10% | 0～50% | 下一条命令 | 同上 | — |
| 失败工作区保留天数 | 3 天 | 1～30 天 | 下次清理（每 6 小时） | 同上 | — |
| 每次运行最多读取网页次数 | 10 | 1～50 | 下次运行 | 同上 | — |
| 自动任务并发 | 2 | 1～20（实际不超过 Runtime 容量减 1） | 下次调度 | 同上 | RP9 |
| 通知保留天数 | 90 天 | 30～365 天 | 下次清理（每天） | 同上 | — |
| 错误记录保留天数 | 90 天 | 30～365 天 | 下次清理（每天） | 同上 | RP6 |
| 页面访问保留天数 | 180 天 | 30～730 天 | 下次清理（每天） | 同上 | RP6 |

| 知识库上传超时 | 120 秒 | 30～600 秒 | 下次上传 | 同上 | RP4 |

**只读展示**（来源“系统内置”或“环境变量”）：执行容器资源（1 GB / 2 核 / 256 进程 / 单命令 600 秒）、Python 沙箱资源（256 MB / 0.5 核 / 单次 290 秒）、工作区上限（2 GB / 5 万文件 / 4 GB 判失败）、产物上限（单个 20 MB / 合计 50 MB / 20 个）、平台工具超时、模型重试次数、后台车道其他并发、数据库连接池、密码哈希并发、发布检查间隔。

### 6.3 接口

- `GET /api/admin/v1/runtime-parameters`：`ops` 查看权限。返回所有登记参数的当前值、默认值、来源、生效时机、修改位置，以及“超时链路”（每条链路的实际生效值与起限制作用的一项）。
- `PUT /api/admin/v1/platform-settings/{key}`：按参数所属模块校验写权限，带 `revision`；写审计 `platform.setting.update`（旧值 → 新值）。
- 业务页面（登录设置、知识库、模型路由）走各自已有或新增的模块接口，内部写同一张表或路由表。

### 6.4 管理端页面

导航“安全与运维”新增一项 **运行参数**（`/runtime-parameters`，`ops` 模块），两个标签：

1. **运维设置**：6.2 中归 `ops` 的参数，分“磁盘与工作区”“并发与运行”“数据保留”三组；每项显示当前值、默认值、范围、生效时机，可编辑、恢复默认；保存时显示变更摘要并二次确认危险项。
2. **参数总览**（只读）：
   - 顶部“超时链路”卡片：员工对话、管理助手、会话摘要、知识库检索、模型请求，各自显示实际生效值和起限制作用的一项；有不一致时标黄并说明（例如“Runtime 超时 3 分钟小于 Agent 超时 5 分钟，实际按 3 分钟”）；
   - 下方按模块分组的表格：参数、当前值、来源、生效时机、修改位置（有权限时为链接，否则显示“需某某权限”）；
   - 支持按来源筛选与搜索。

业务页面：

- **员工与权限**：新增“登录设置”卡片（会话有效期）。
- **企业知识库**：新增“连接与超时”区块，连接地址与嵌入模型只读、检索与上传超时可改。
- **模型治理 → 路由编辑**：新增“首个响应超时”。
- **Agent 详情 → 能力** 与 **Runtimes 配置弹窗**：运行超时旁显示实际生效值，Agent 超时大于 Runtime 超时时提示（RP7）。

## 8. 验收

- **单元：** 登记表校验（范围、类型、权限归属）、超时链路计算、保留期清理按配置值。
- **PostgreSQL 集成：** 参数读写与乐观锁、审计、按模块权限拒绝、页面值优先于环境变量。
- **P0 浏览器冒烟：** 运行参数页两个标签可打开，修改一个运维参数后总览同步；只有某模块查看权限时“去修改”不可点。
- **P1 受控 Runtime：** 读取网页上限改为 1 后第二次读取被拒；磁盘阈值调高后命令被拒并提示。
- 验收旅程写入 `e2e/catalog/admin-platform.md`。
