# M4-08 审计与运营退出检查

**工程结论：** M4-08 已把管理操作、安全授权、运行、模型、工具和成果六类事实统一投影为只读运营事件，提供近 24 小时汇总、筛选、脱敏导出和按 Run 下钻。该结论关闭单机 MVP 的审计查询工程基线，不代表生产日志平台、长期归档和告警值班已经完成。

## 1. 完成范围

| 能力 | 状态 | 验证口径 |
|---|---|---|
| 六类事件统一查询 | 已完成 | `operational_events` 只读视图合并 `audit_events`、`run_events`、`model_usage_events`、`tool_audit_logs` 和 `artifact_versions` |
| 运营汇总 | 已完成 | 近 24 小时运行成功/失败、Token、工具、成果和需关注事件由 PostgreSQL 聚合 |
| Run 下钻 | 已完成 | 单个 Run 返回运行、模型、工具和成果安全时间线，非法 Run 拒绝查询 |
| 管理对象类型 | 已完成 | Agent、Skill、工具、连接器、运行时与 Run 不再被统一误记为 `run` |
| 脱敏 | 已完成 | 统一投影不读取 `display_message`、消息正文、提示词、回答正文或文件内容；只返回预先约束的安全元数据 |
| 管理端 | 已完成 | 类型、结果、关键词筛选，真实 24 小时指标，详情抽屉、Run 时间线和脱敏 JSON 导出 |
| 运营概览 | 已完成 | 移除运行分布、增幅和风险事项的原型硬编码，改用真实运行及运营事件 |

## 2. 数据边界

- 运营事件是跨事实表的只读投影，不复制或修改权威业务记录。
- 模型事件只包含 Provider、模型、Token、时延、费用和估算标记。
- 工具事件只包含治理后的工具版本、权限决策结果和参数类型摘要；允许决策记为成功，拒绝或取消记为 `blocked`，不能把“收到权限请求”误报为完成调用。
- 成果事件只包含成果、版本、文件对象标识和来源 Run，不包含文件内容。
- 管理端默认最多读取最近 500 条事件；生产保留期、归档和分区策略进入 M5。
