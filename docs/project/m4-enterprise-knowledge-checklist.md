| 验收项 | 结论 | 验收证据 |
|---|---|---|
| 知识源 | 已完成（受控基线） | PostgreSQL 管理一个 `managed-catalog` 知识源；两份制度文档明确标记为合成测试数据，可由后续外部适配器替换 |
| 文档版本 | 已完成 | 文档标识、版本、生效日期、数据范围和内容校验值独立持久化；已发布版本禁止原地修改 |
| 权限过滤 | 已完成 | 检索前校验用户角色；需要工作空间的文档同时校验工作空间 ID 和成员关系，未授权内容不进入检索候选集 |
| 检索 | 已完成（MVP） | 对授权候选按关键词、标题和正文相关性评分，设置最低阈值并最多选择 3 份文档 |

| 来源追溯 | 已完成 | 每个 Attempt 保存实际采用的文档、相关性和摘要；员工对话详情展示标题、版本、生效日期、数据范围及合成数据标识 |
| 重试语义 | 已完成 | 每个 Attempt 重新按当前权限解析知识，并分别保存来源快照；历史 Attempt 不被覆盖 |
| 自动化验证 | 已完成 | 真实 PostgreSQL 测试覆盖角色过滤、工作空间过滤、Manifest 注入、回答来源、员工端来源 DTO 和发布版本不可变 |

## MVP 边界

- 当前知识内容来自项目受控合成数据，不代表企业制度，不得用于真实业务决策。
- 当前检索采用 PostgreSQL 候选集加确定性关键词相关性，不引入向量数据库；两份基线文档不需要额外检索基础设施。
- 当前不提供知识文档上传、审批和发布后台；正式来源确定后再按企业内容治理流程建设。
- D-06 仍需确认真实知识库 API 或文档目录、文档 Owner、版本口径、数据范围和更新机制，才能进入真实知识 UAT。
