## MVP 测试边界

- 当前“测试 Agent”是服务端配置测试：验证完整配置、权限引用和配置指纹，并形成发布门禁证据。
- 员工发起真实会话后，已发布配置会进入不可变 Runtime Manifest 并由 DSH 执行真实模型链路。
- 将发布前测试升级为隔离 DSH 试运行、效果评测集与质量阈值属于后续增强，不阻塞 M4-01 MVP 工程退出。

## 保留边界

- 企业 SSO 尚受 D-03 约束；当前负责人和员工身份来自服务端受控种子用户，正式试点前必须切换企业身份映射。
- M4-02 Skill 生命周期、M4-03 预置 Tool/Connector、M4-06 完整权限矩阵仍需分别关闭。
- Agent 不保存 Provider、密钥或模型策略；模型与密钥继续由平台级模型治理和 DSH 受管 Runtime 负责。
