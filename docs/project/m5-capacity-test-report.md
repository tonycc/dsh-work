## 验证内容

- PostgreSQL 在事务锁内读取 Runtime `capacity`，活动 Attempt 达到上限后保持 `queued`。
- 容量释放后调度泵继续认领排队 Attempt，50 个 Run 无丢失、无重复、无越界。
- 每个 Run 保持独立 Attempt、事件序列、结果和终态。
- 容量测试使用真实 Repository、状态机、编排和 PostgreSQL，仅替换外部 DSH/模型执行时间。
- 测试命令已加入 GitHub Actions PostgreSQL Job。

## 明确边界

- D-08 的目标 Mac mini 型号、内存、磁盘、UPS 和网络尚未确定，本报告不能锁定生产并发值；正式环境必须按相同方法重跑。
- R-15 已关闭；正式并发值仍需在 D-08 目标硬件上重新执行真实 1/3/5 并发探针。
- 当前未覆盖 20 MB 文件并发、长对话 Token 压力和真实 Connector 延迟；需在 D-05、D-07、D-08 确定后进入预生产容量测试。
- CPU、内存、磁盘的持续采集、阈值和告警属于 M5-07，本项只形成测试快照。
- 本报告关闭 M5-04 工程 Gate，不等于生产容量签署或试点 Go-Live 已通过。
