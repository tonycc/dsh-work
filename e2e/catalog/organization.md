# 组织架构

设计见[企业组织架构方案](../../docs/design/org-structure-plan.md)。本分册覆盖第一期 ORG-S1（部门树与成员）；部门授权（ORG-S2）实施时补充条目。证据层级与写法见[验收目录索引](../TEST-CATALOG.md)。

### ORG-P0-01 管理端组织架构页可维护部门树与成员

**优先级：** P0 · **角色：** 平台管理员（冒烟测试身份） · **运行层级：** P0 冒烟服务、内存数据<br>
**前置数据：** 冒烟服务提供一棵部门树（根部门、若干一级与二级部门）、已分配与未分配部门的员工<br>
**spec：** `e2e/organization.spec.ts`

1. 从“组织与权限”导航进入“组织架构”，直接看到部门树和当前部门的成员，没有首次使用的引导或导入步骤；统计卡片显示部门数、已分配与未分配部门的员工数。
2. 在部门树中选中一个部门，右侧显示部门路径、直属成员数、含下级成员数与下级部门数；有下级的部门可以展开和收起。
3. 新建子部门后出现在树中；同一上级下重名时提示且不创建。改名后树与成员的部门显示同步更新。
4. 添加成员时可多选，可“只看未分配部门的员工”；未分配的员工加入后以该部门为主部门。
5. 移出某员工的主部门且其还属于其他部门时，要求指定新的主部门；勾选“包含下级部门成员”可看到整棵子树的成员。
6. 删除仍有成员或下级部门的部门被拒绝并说明原因；根部门不能移动或删除。

**验收：** 关键操作有成功提示，表单有可访问名称，窄屏下树与成员列表可操作。

### ORG-01 部门树维护与约束

**优先级：** P1 · **角色：** 平台管理员、只读管理员 · **运行层级：** 专用可丢弃 PostgreSQL、受控测试身份、真实 HTTP 接口<br>
**前置数据：** 迁移后的企业只有根部门<br>
**spec：** `server/src/http/organization-api.integration.test.ts`

1. 迁移为企业创建且只创建一个根部门，名称为企业名称；读取组织架构不写入数据。
2. 新建多级部门；同一上级下重名被拒绝，不同上级下可以同名；名称为空或过长被拒绝。
3. 改名、调整排序后读取结果一致；移动部门时整棵子树随之移动，不能移动到自己或自己的下级之下，根部门不能移动、改名之外的修改或删除被拒绝。
4. 删除有下级部门或有成员的部门被拒绝；删除空部门后不再出现在树中，之后可以新建同名部门。
5. 没有管理写权限的管理员读取成功、写入被拒绝；每次写入留下审计记录。

**验收：** 树结构始终无环、路径正确，并发移动不会产生环。

### ORG-02 成员、主部门与显示部门

**优先级：** P1 · **角色：** 平台管理员 · **运行层级：** 专用可丢弃 PostgreSQL、受控测试身份、真实 HTTP 接口<br>
**前置数据：** 两级部门树；若干有效员工，其中部分已分配部门<br>
**spec：** `server/src/http/organization-api.integration.test.ts`

1. 一次添加多名员工到部门：未分配的员工以该部门为主部门，已有主部门的员工保持原主部门；重复添加幂等；停用或不存在的员工被拒绝。
2. 员工的显示部门（员工列表、员工端个人信息中的“部门”）等于主部门名称；改主部门、主部门改名后同步更新；没有部门时显示“未分配部门”。
3. 移出主部门且仍属于其他部门时，必须指定其中一个作为新的主部门，否则被拒绝；移出唯一部门后变为未分配。
4. 每名员工始终至多一个主部门。

**验收：** 成员关系与显示部门在同一事务中更新，读取结果与操作一致。

### ORG-03 新建账号选择部门，上线不保留历史部门文本

**优先级：** P1 · **角色：** 平台管理员 · **运行层级：** 专用可丢弃 PostgreSQL、受控测试身份<br>
**前置数据：** 迁移前已有填写了部门文本的员工；一棵部门树<br>
**spec：** `server/src/http/organization-api.integration.test.ts`、`e2e/local-auth.integration.spec.ts`

1. 迁移后所有独立账号员工的部门文本被清空，显示“未分配部门”，不转为任何部门（AI Hub 账号的部门文本由目录同步维护，迁移不清空）。
2. 管理员在“员工与权限”新建账号时从部门树选择部门（可以不选）：选中的部门成为该员工的主部门；不再接受自由填写的部门文字；选择已删除或不存在的部门被拒绝且不创建账号。
3. 初始化首个管理员不再写入部门文本。

**验收：** 部门只能通过部门树分配，员工自填或历史文本都不产生成员关系。

### ORG-04 AI Hub 登录模式下不可用

**优先级：** P1 · **角色：** 平台管理员 · **运行层级：** 专用可丢弃 PostgreSQL、受控测试身份<br>
**前置数据：** 以 AI Hub（OIDC）登录模式启动的组织架构服务<br>
**spec：** `server/src/http/organization-api.integration.test.ts`

1. 读取组织架构返回“不可用”，页面显示说明而不是部门树。
2. 新建、修改、删除部门及成员操作均被拒绝，不写入数据。

**验收：** 方案 OD1：组织架构只面向本地身份模式。
